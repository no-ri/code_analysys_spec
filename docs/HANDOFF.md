## 5. 環境メモ（実測済み・再確認不要）

- `sqlite3` は **Python 本体に同梱**。単体インストール不要
- **tree-sitter**: `pip install tree-sitter tree-sitter-language-pack` の**1コマンドで完了**。
  追加依存なし、C コンパイラ不要、計約 7.6MB、371言語対応、対象6言語すべて対応、MIT
- **tree-sitter のエラー回復**: 式の破損・未知のマクロ修飾からは**完全に回復**するが、
  **括弧の不均衡は後続を巻き込んで全滅**する（実測 0/3）
- **tree-sitter の速度**: 1.7MB / 20,000行の C を 0.77 秒。ただし**抽出は S 式クエリで書くこと**
  （Python 側で木を走査すると 2.37 秒 → クエリなら 0.26 秒、約9倍）
- **`#ifdef` は両枝が構文木に載る**。これは簡易版がフル版より強い領域でもある
  （フル版は1構成しかパースしないので Linux 上では `#ifdef _WIN32` の中身が見えない）
- `.ps1` は **UTF-8 BOM 必須**。`.gitattributes` で `.ps1` は CRLF、`.sh` は LF に固定済み
- **`--depth 1` の shallow clone では git の変更頻度が測れない**（全ファイル一律 1 件になる）。
  §8.4 の推奨セットはすべて shallow clone で取得している
